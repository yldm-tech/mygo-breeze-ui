# breeze-ui-cli

The CLI for Breeze UI, a third-party Tailwind-style native UI system for MyGo.

```sh
npx breeze-ui init
npx breeze-ui list -kind component
npx breeze-ui add Button -o ui/button_snippet.go
```

For a released binary, install the Go command directly:

```sh
go install github.com/yldm-tech/mygo-breeze-ui/cmd/breeze-ui@latest
```
